## Projects

### 3DTowerDefense
Unity와 C#의 기본 기능을 학습하며 제작한 간단한 3D Tower Defense 프로젝트입니다.

Waypoint 기반 적 이동, 타일 기반 타워 설치, 범위 내 적 탐색 및 공격 기능을 구현했습니다.

[Repository](https://github.com/dice842/3DTowerDefense)

### UniSideGame
Unity 2D 게임 제작을 학습하며 제작한 횡스크롤 게임 프로젝트입니다.

플레이어 이동과 점프, 적과 포탄, 제한시간, 게임오버 및 스테이지 클리어 기능 등을 구현했습니다.

[Repository](https://github.com/dice842/UniSideGame)

### GamePrototype
2D 탑다운 액션 게임의 여러 기능을 구현하고 테스트하기 위해 제작한 프로토타입 프로젝트입니다.

플레이어 이동, 스태미너, 총기와 투척물, GOAP 기반 AI 등의 기능을 실험했으며 이후 일부 아이디어와 기능은 다른 프로젝트로 발전했습니다.

[Repository](https://github.com/dice842/GamePrototype)
